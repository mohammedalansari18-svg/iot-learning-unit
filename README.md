# إنترنت الأشياء: التصميم والأخلاقيات والأمن

وحدة تعليمية تفاعلية (صفحة واحدة `index.html` بلا أي اعتماديات خارجية) تغطي:

- **الوحدة الثالثة (RLO3) – تصميم أنظمة إنترنت الأشياء:** مراحل التصميم، معايير التصميم الجيد، نشاط سحب وإفلات «صمّم نظام المدرسة الذكية»، وتطبيق «اتخذ القرار المناسب».
- **الوحدة الرابعة (RLO4) – الأخلاقيات والأمن:** حماية الخصوصية، الأمن السيبراني، المسؤولية والاستخدام الرشيد، وتقويم بالمواقف.

## التشغيل

افتح `index.html` في أي متصفح.

## النشر على GitHub Pages

من إعدادات المستودع: **Settings → Pages → Source: Deploy from a branch → main / (root)**، ثم افتح الرابط الذي يظهر.
